# 쇼츠 제작 워크플로우 (전 채널 공통)

이 프로젝트는 Remotion 멀티채널 쇼츠다. 사용자가 채널 작업을 시작하면 아래 순서를 **항상** 따른다.
대상 채널: 현재 `대환장민국`(headline 레이아웃), `안빤엄빠`(board 레이아웃). 앞으로 늘어날 수 있다.

---

## 트리거

사용자가 **"자 xxx 작업 시작하자"** (xxx = 대환장민국 / 안빤엄빠 등) 라고 하면 이 절차를 시작한다.

## 절차 (순서 고정) — 녹음 기반

1. **제목을 물어본다.**
   - "제목 뭐로 할까요?" 하고 사용자가 제목을 줄 때까지 기다린다. 제목을 임의로 정하지 않는다.

2. **제목을 받으면 스크립트가 준비돼 있는지 물어본다.**
   - 사용자가 스크립트를 주면 그대로 사용(다듬기는 확인 후).
   - "없다"고 하면 **내가 제목 기반으로 스크립트를 만든다.** 채널 페르소나/글자수/말투 스티어링을 반드시 준수(대환장민국은 `daehwanjang-persona.md`).

3. **스크립트(인트로 포함)를 사용자에게 검사받는다.**
   - 인트로 문장 + 본문을 **줄글로** 보여주고 승인/수정 받는다. 승인 전에는 다음 단계로 넘어가지 않는다.

4. **사용자가 녹음한다. (음성이 타이밍의 기준)**
   - 사용자가 직접 내레이션을 녹음하고, 더듬은 구간·숨 구간을 잘라서 **`audio/` 폴더에 넣는다**(mp3/wav 등).
   - 즉 **자막 타이밍을 손으로 추측해 넣지 않는다.** 녹음이 오기 전엔 자막 비트를 만들지 않는다.

5. **오디오를 자동 전사한다.**
   - `node scripts/transcribe.mjs <채널id>` 실행 → whisper.cpp(한국어 medium)가 전사 →
     `src/channels/<채널>/narration.generated.ts` 에 자막 비트(`generatedNarration`)를 생성.
   - script.ts 에서 그걸 `narration` 으로 연결한다. (오디오 자체는 영상에 삽입)

6. **전사 결과에 맞춰 영상 작업을 한다.**
   - 자막(전사 비트) 싱크 확인/미세 교정 → 컷(사진) 배치 → 효과음 배치. 전부 **녹음 타이밍에 맞춘다.**
   - 승인 후 렌더.

## 제작 구조 (중요 — 스크립트 → 녹음 → 전사 순)

```
① 제목
② 스크립트(인트로 포함)   ← 내용 기준, 사용자 검사
③ 사용자 녹음 → audio/    ← 타이밍 기준 (더듬음·숨 제거된 상태로 공급)
④ 자동 전사(transcribe.mjs) → narration.generated.ts  ← 자막 비트 자동 생성
⑤ 자막 싱크 확인 + 컷(사진) 배치 + 효과음 배치  (모두 녹음 타이밍 기준)
⑥ 오디오를 영상에 삽입하고 렌더
```

- **자막 타이밍**: 반드시 녹음 전사에서 나온다. 임의의 start 초를 사람이 찍지 않는다(오디오 없을 때 임시 미리보기 제외).
- **효과음**: 제목/스크립트가 바뀌면 컷 구성도 바뀌므로 매번 다시 분배. 사용자 세트(`public/sfx/`, `s01~s14`, 매핑 `src/types.ts`의 `SFX_FILES`)를 골고루. headline 레이아웃은 **사진 전환마다**(cuts[].sfxOnEnter).
- **사진**: 사용자가 실제 이미지를 주면 사용, 없으면 채널 photoSet SVG로 대체(`MediaBox.tsx`에서 `<Img>`/`<OffthreadVideo>`).
- **레이아웃(headline)**: 상단 블록(제목+배경)·중앙 미디어·하단 블록(자막+배경)은 **서로 독립 영역**이다(`HeadlineShorts.tsx`의 TOP_BLOCK / MEDIA / BOTTOM_BLOCK 상수). 자막은 사진에 묶이지 않고 하단에 고정.
- **제목/인트로/스크립트는 매번 다르다.** 하드코딩된 예시에 얽매이지 말고 그때 값으로 채운다.

## 아직 녹음이 없을 때

- 사용자가 "일단 스크립트만" / "구조만" 이라고 하면 스크립트 작성·검사까지만 하고 멈춘다.
- 미리보기가 필요하면 임시 타이밍으로 렌더할 수 있으나, **최종 자막 싱크는 녹음 전사로 대체**한다고 명확히 안내한다.

## 렌더 & 검증

- 렌더 전 `npx tsc --noEmit`로 타입체크.
- 영상: `node scripts/render.mjs <채널id>`, 썸네일: `node scripts/render.mjs <채널id> --thumb`.
- 결과물: `out/<채널한글명>_YYMMDD.mp4` / `.png`.
- mp4가 잠겨 rename(EPERM) 에러가 나면, 기존 `out/<...>.mp4`와 `*.remotion-in-progress`를 지우고 다시 렌더.
- 렌더 후 필요하면 프레임을 뽑아 확인하고, 확인용 임시 파일은 정리한다.

## 진행상황 보고
