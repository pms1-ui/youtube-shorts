# 대환장민국 — 채널 페르소나 & 대본 작성 규칙

이 문서는 **대환장민국 채널의 대본(`src/channels/daehwanjang/script.ts` 등)을 작성·수정할 때 항상 따른다.**
다른 채널(안빤엄빠 등)에는 적용하지 않는다.

---

## 1. 페르소나 & 말투 (실제 채널 톤)

**"내가 직접 찾아보고 리액션하는" 구어체 관찰자.**
뉴스 앵커나 격식체 논객이 아니라, 커뮤니티/영상에서 뭔가를 발견하고 혼잣말하듯 풀어주는 화자다.

- **시점**: 1인칭 관찰자. 시사 현상을 하나씩 짚어주며 풀어준다.
- **어조**: **존댓말 구어체.** 문장을 **~습니다 / ~죠 / ~인데요 / ~가요(나요) / ~겁니다 / ~거죠** 로 맺는다. 격식체 논설조도 아니고 반말도 아닌, 친근하게 설명하는 유튜브 내레이션 톤.
- **리듬**: 짧게 끊어 말하고, "요즘", "근데", "재밌는 건", "심지어", "솔직히" 같은 연결어로 자연스럽게 이어간다.
- **태도**: 단정적으로 훈계하지 않는다. 씁쓸함·어이없음·궁금함 정도로, 판단은 열어둔다.

### 말투 필수 규칙 (존댓말 구어체 — 반드시 준수)
- 기본 종결: **"~습니다", "~죠", "~인데요", "~거죠", "~겁니다", "~나요/가요"**
  - 예) "완전히 갈렸습니다", "자산을 불렸는데요", "출발선이 다른 겁니다", "보수화가 뚜렷해졌습니다"
- **★ "~인데요" 연속 금지.** 한 문장을 "~는데요"로 맺었으면 **다음 문장은 "~습니다 / ~죠 / ~겁니다"로 교차**한다(같은 종결 연달아 X).
  - 나쁜 예: "갈렸는데요, / 불렸는데요. / 가버렸는데요." (연속)
  - 좋은 예: "심상치 않은데요. → 완전히 갈렸습니다. → 자산을 불렸는데요. → 가버렸죠."
- **되묻기·자문형 말투 금지**: "계층 사다리요?", "이게 말이 되나요?" 같은 되묻기 도입은 쓰지 않는다. 그냥 평서문으로 단언한다("계층 사다리는 이미 끊긴 지 오래입니다").
- 금지 종결: 명사형(~함/~임/~듯/~음), 반말(~했어/~더라고/~하잖아). 존댓말 구어체로 통일.

### 전개 구조 (이 순서로 쓴다)
1. **인트로 = 항상 첫 문장 = 제목형 후킹** ("~ 근황" 등). 인트로는 헤드라인과 동일 문구.
2. **도입/상황 제시**: "요즘 ~ 진짜 심상치 않은데요." 식으로 현상 던지기.
3. **사례·근거 제시**: 대비/통계/비유를 하나씩 단언조로.
4. **심화**: 더 깊은 포인트("재밌는 건 ~", "심지어 ~").
5. **마무리**: 씁쓸한 전망 한 줄로 담담하게 닫는다("앞으로 더 심해질 텐데, 솔직히 어떻게 될지 모르겠습니다"). 억지 되묻기로 끝내지 않는다.

### 주제·안전
- 대환장민국은 대한민국 현재/미래를 짚는 시사. 가볍고 흥미롭게 다루되 단언은 담담하게.
- **특정 집단·세대를 조롱하는 표현·명칭 금지**(예: "스윗영포티" 같은 조롱조 대신 "영포티" 같은 중립 표현). 특정 실존 인물 조롱·허위 단정 금지.
- 통계·수치·정치 성향 서술은 **콘텐츠용 예시(가상 창작)**로 다루고 실존 통계의 단정적 인용처럼 쓰지 않는다.
- 비하·혐오 없이, 씁쓸함/궁금함 정도의 톤.

### 말투 레퍼런스 (확정 톤 — 이 느낌으로)
> "요즘 세대 갈등이 진짜 심상치 않은데요. MZ랑 영포티, 두 세대가 완전히 갈렸습니다. 영포티는 집값 오를 때 딱 올라타서 자산을 불렸는데요. MZ는 취업도 안 되는데, 집값은 이미 저 위로 가버렸죠. … 앞으로 이 갈등이 더 심해질 텐데, 솔직히 어떻게 될지 모르겠습니다."

> 위 예시는 말투·리듬 레퍼런스다. 실제 대본은 아래 "쇼츠 글자수 제한"에 맞춰 **짧은 비트로 잘게 쪼갠다.**

## 2. 쇼츠 글자수 제한 (headline 레이아웃 기준 — 반드시 준수)

대환장민국은 `layout: "headline"`(검정 배경 + 상단 고정 헤드라인 2줄 + 중앙 미디어 + 하단 교체형 자막).
세로 1080×1920, 좌우 여백 40px씩이라 가로가 좁다. **글자가 넘치면 줄바꿈되어 레이아웃이 깨진다.** 아래 한도를 지킨다.

| 요소 | 필드 | 권장 한도(공백 포함) | 절대 상한 |
|------|------|------|------|
| 상단 헤드라인 1줄 (하양) | `headline.line1` | **8~10자** | 12자 |
| 상단 헤드라인 2줄 (노랑, 강조) | `headline.line2` | **6~9자** | 11자 |
| 하단 자막 비트 (한 줄) | `narration[].text` | **8~16자** | 18자 |

규칙:
- **헤드라인 2줄**은 영상 내내 고정되는 **후킹 카피**다. 짧고 강하게. (예: 1줄 "대한민국을 가르는" / 2줄 "빈부격차 실화")
- **하단 자막은 한 비트에 한 줄.** 절대 두 줄로 넘기지 않는다. 길면 비트를 쪼갠다.

---

## 2-1. ★ 줄글 스크립트 원칙 (가장 중요 — 반드시 준수)

이 채널 자막은 "제목 나열"이 아니라 **말하듯 이어지는 줄글 내레이션**이다.
진짜 쇼츠처럼 **속도감 있게 쫙쫙** 전개되어야 한다.

- 구어체 문장을 **짧은 조각으로 잘게 끊어** `narration[]` 비트로 흘린다.
  - 예) "빈부격차 때문에 말 많은데" → "직접 찾아봤더니" → "상위 10%가" → "부의 절반 넘게 쥐었더라고"
- **비트 간격 0.8~1.3초**. 한 비트는 눈에 확 들어오는 8~16자. (한 호흡에 읽히는 분량)
- 비트는 **문맥이 이어지게** 쓴다. 말하듯 앞뒤가 하나의 이야기로 연결(단독 슬로건 나열 금지).
- **전개 = 예시 5개 로직**: 인트로(제목 후킹) → 상황 제시 → 직접 조사 → 사례+리액션 → 되묻기/반전 마무리.
- **첫 비트(start:0)는 항상 인트로 문장과 같은 후킹**이고, 인트로 카드가 끝난 뒤 본편 첫 비트로 이야기를 시작한다.
- 자막 색은 코드에서 **항상 하양 고정**이라 `color`는 신경 쓰지 않아도 된다(넣어도 무시됨).
- 효과음은 자막이 아니라 **사진 전환(cuts[].sfxOnEnter)마다** 울린다. 컷 성격에 맞춰 s01~s14를 골고루 배치.
- 전체 길이 20~30초 목표. 비트 20~26개 내외가 적당.

## 2-2. 사진(미디어) 트랙

- 사진은 `cuts[]`가 담당하며 **자막보다 느리게** 장면 단위로 교체한다(여러 자막 비트가 한 사진을 공유).
- 각 `cut`: `start`(초), `photo`(DH_PHOTOS 키), `zoom`("in"/"out"). `lines:[]`, `source:""`는 타입 충족용 빈값.
- 보통 6~8개 장면. 사진 전환 시점은 내레이션의 문단(주제) 전환과 맞춘다.

## 3. 대본 구조 규칙 (기술)

- 파일: `src/channels/daehwanjang/script.ts`, 타입 `StoryScript`.
- 필수: `headline{ line1, line2 }`, `narration[]`(자막), `cuts[]`(사진).
- `narration[]` 비트: `{ start, text, color?, sfx? }`. 이게 **주 자막 트랙**이다.
- `cuts[]` 컷: `{ start, photo, zoom?, lines:[], source:"" }`. 사진 전용.
- `title`/`views`/`comments`는 board 레이아웃 잔재이나 타입상 유지(화면 미표시).
- `photo`는 `src/channels/daehwanjang/photos.tsx`의 `DH_PHOTOS` 키만 사용. 새 주제면 SVG 먼저 추가.
- 직렬화 규칙: channel/script는 문자열·숫자 등 직렬화 가능한 값만. 함수/컴포넌트 금지.
